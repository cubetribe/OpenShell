# Roadmap

- define workspace shape

- validate the chosen host platform

- define baseline filesystem policy

- validate the target agent workflow
- confirm required endpoints and binaries
- capture known limitations and workarounds

## Phase 5: Deployment Path

- decide local-only vs remote-host architecture
- document rollout sequence
- add automation, checks, and release process

## Blocking Inputs

- first target platform for validation
