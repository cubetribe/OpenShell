# Decision Log

Use this directory for ADR-style records once major choices begin to solidify.

Recommended filename pattern:

- `YYYY-MM-DD-short-title.md`

Recommended template:

1. Context
2. Decision
3. Consequences
4. Follow-up work

Likely early decisions:

- first supported host platform
- first supported agent
- whether to track upstream repo directly or keep this workspace separate
- whether policies live in this repo from the beginning
